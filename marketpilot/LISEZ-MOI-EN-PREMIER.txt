MARKETPILOT — INSTALLATION EN 10 MINUTES
========================================

Tout est inclus dans ce dossier (Node.js aussi) : rien d'autre à installer.
Il te faut seulement Google Chrome, connecté à ton compte Facebook, et ton
cellulaire sur le même Wi-Fi que ton ordinateur.


1. DÉMARRER (la première fois)
------------------------------
- Mets ce dossier MarketPilot dans un endroit fixe, par exemple Documents
  (pas dans Téléchargements, que Windows nettoie parfois).
- Double-clique  DEMARRER-Windows.bat
  Si Windows affiche « Windows a protégé votre ordinateur » :
  clique « Informations complémentaires », puis « Exécuter quand même ».
- Une page s'ouvre pour créer ta clé API Anthropic :
  « Create Key », copie la clé (elle commence par sk-ant-), colle-la dans la
  fenêtre noire et appuie sur Entrée. La clé est vérifiée tout de suite.
  Ajoute 5 à 10 $ de crédit dans « Billing » (environ 0,10 $ par annonce).
- Si le pare-feu de Windows te demande l'accès : coche « Réseaux privés »
  et clique Autoriser. C'est ce qui permet à ton cell de se connecter.
- Un raccourci « MarketPilot » est créé sur ton bureau. Les prochaines fois,
  double-clique simplement ce raccourci.

LAISSE LA FENÊTRE NOIRE OUVERTE pendant que tu vends.


2. AJOUTER L'EXTENSION À CHROME
-------------------------------
La page des extensions de Chrome s'ouvre toute seule, et l'emplacement du
dossier de l'extension est déjà copié.
  a) Active « Mode développeur » (en haut à droite).
  b) Clique « Charger l'extension non empaquetée ».
  c) Dans la fenêtre, clique dans la barre d'adresse en haut, colle (Ctrl+V),
     appuie sur Entrée, puis « Sélectionner un dossier ».
  d) Clique la pièce de casse-tête 🧩 et épingle MarketPilot.
  e) Clique sur l'icône MarketPilot : le panneau s'ouvre et se connecte tout
     seul (« ✅ Connecté automatiquement »). Aucun jeton à copier.


3. INSTALLER L'APP SUR TON CELLULAIRE
-------------------------------------
- Scanne le code QR avec l'appareil photo de ton cell : celui du panneau
  Chrome, ou celui de la fenêtre noire.
  Code illisible ? Ouvre http://localhost:8787/m/qr dans Chrome sur le PC.
- Ajoute la page à l'écran d'accueil :
    iPhone : bouton Partager ⬆️, puis « Sur l'écran d'accueil ».
    Android : menu ⋮, puis « Ajouter à l'écran d'accueil ».


4. VENDRE
---------
Sur le cell, dans l'app MarketPilot, pour chaque article :
  📷 Photo (3 à 8 photos, la meilleure en premier), une note si tu veux
  (🎤 pour dicter), la stratégie (Vendre vite / Équilibré / Max $),
  puis « Article suivant ».

En 1 à 3 minutes, l'IA identifie l'article, rédige l'annonce et Chrome trouve
le prix du marché. La fiche passe à « ✅ Prête à publier » avec 3 prix au choix.

Pour publier :
  - Le plus simple, sur le PC : panneau Chrome, bouton « 🚀 Tout publier ».
    Chaque annonce s'ouvre toute remplie ; tu cliques « Publier » sur
    Facebook, et la suivante s'ouvre.
  - Depuis le cell : « 📤 Publier depuis le cell ». Le texte est copié.
    Enregistre les images, puis dans Facebook : Marketplace, Vendre,
    Articles. Choisis les photos, colle le texte dans Description, puis
    « Publier ». Reviens ensuite toucher « C'est publié ✔ ».


ENSUITE, CHAQUE JOUR
--------------------
- Panneau Chrome, onglet « Annonces » : « Synchroniser avec Facebook ».
  Ça relie tes annonces, compte les clics et les acheteurs.
- Un acheteur t'écrit ? Ouvre la conversation dans Chrome et clique
  « ✨ Réponse IA » : la réponse s'écrit dans la zone de message. Tu relis et
  tu appuies sur Entrée. Rien n'est jamais envoyé sans toi.
- Onglet « Décisions » (aussi sur le cell) : les baisses de prix proposées.
  Rien ne baisse sans ton accord, jamais sous ton prix plancher.
- Vendu ? Clique « Vendu » dans MarketPilot, et marque-le vendu sur Facebook.


SI ÇA BLOQUE
------------
- Le panneau dit « MarketPilot ne répond pas » : la fenêtre noire est fermée.
  Double-clique le raccourci MarketPilot sur le bureau.
- Le cell n'ouvre pas la page :
    - vérifie que le cell est sur le même Wi-Fi que le PC (pas en données
      cellulaires) ;
    - autorise Node.js dans le pare-feu Windows (Paramètres, Confidentialité
      et sécurité, Sécurité Windows, Pare-feu, Autoriser une application).
- Une fiche reste sur « Prix du marché » : Chrome est fermé ou n'est pas
  connecté à Facebook. Sinon, clique « Scanner maintenant » sur la fiche.
- « IA inactive » ou erreurs d'IA : vérifie ton crédit sur platform.claude.com.
  Pour changer de clé : supprime le fichier server\.env et relance.
- Un champ Facebook ne se remplit pas : complète-le à la main et envoie une
  capture d'écran pour qu'on ajuste.

Pour vendre de partout sans laisser le PC allumé : voir DEPLOIEMENT-EN-LIGNE.md.
